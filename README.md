# 🍣 回らない寿司打

「寿司打」をパロディにした、高級寿司店のカウンター席でタイピング修行を行うWebアプリケーションです。

## 🎮 ゲームの特徴

- **3つのコース**: お手軽（3,000円/60秒）、お勧め（5,000円/90秒）、高級（10,000円/120秒）
- **表記ゆれ対応**: ローマ字入力の複数パターンに対応（例：「ちゃ」→cha/cya/tya）
- **ボーナスシステム**: ミスなく連続で打つとボーナスポイント獲得
- **リアルタイム表示**: ミスなし連続文字数をバーで表示
- **高級寿司店の雰囲気**: SVGで描画された寿司ネタとカウンター席

## 🔧 セットアップ

### GitHub Pagesでのデプロイ

1. このリポジトリをGitHubにプッシュ
2. リポジトリの Settings → Pages を開く
3. Source を「main」ブランチに設定
4. 表示されるURLにアクセス

### ローカルでの実行

HTTPサーバーを立ち上げる必要があります：

```bash
# Pythonを使う場合
python -m http.server 8000

# Node.jsを使う場合
npx http-server

# VSCodeのLive Serverを使う場合
右クリック → Open with Live Server
```

その後、ブラウザで `http://localhost:8000` にアクセス。

## 🎵 音声ファイルについて

現在、`sounds/` ディレクトリ内の音声ファイルはプレースホルダーです。実際の音声を使用する場合は、以下の形式で音声ファイルを準備してください：

### 必要な音声ファイル

- **typing.mp3**: キーをタイプした時の音（短い「カタッ」という音）
- **correct.mp3**: 正しくタイプした時の音（「ピコン」など）
- **miss.mp3**: ミスタイプした時の音（「ブー」など）
- **complete.mp3**: 1文完成時の音（「ポン」など）
- **combo.mp3**: コンボ達成時の音（「シャラーン」など）
- **bgm.mp3**: ゲーム中のBGM（落ち着いた和風音楽）
- **result.mp3**: リザルト画面のBGM

### 推奨形式

- フォーマット: MP3（ブラウザ互換性のため）
- サンプリングレート: 44.1kHz
- ビットレート: 128kbps以上
- 効果音の長さ: 0.1〜1秒程度
- BGMの長さ: 1〜3分程度（ループ可能な構成）

## 🎯 ゲームの遊び方

1. **コース選択**: スタート画面で3つのコースから選択
2. **タイピング**: 表示された文章をローマ字でタイプ
3. **コンボ**: ミスなく連続でタイプするとボーナス
4. **結果**: 時間切れ後、獲得ポイントとコース料金の差額を確認

### 表記ゆれの例

- 「し」→ `si` / `shi`
- 「ち」→ `ti` / `chi`
- 「つ」→ `tu` / `tsu`
- 「ふ」→ `hu` / `fu`
- 「ちゃ」→ `cha` / `cya` / `tya`
- 「じゃ」→ `ja` / `jya` / `zya`
- 「ん」→ `nn` / `n`（後続の文字による）

## 🎨 カスタマイズ

### 文章データの追加

`data/phrases.json` を編集して、タイピング用の文章を追加できます：

```json
{
  "easy": [
    {
      "display": "表示される文章（漢字入り）",
      "hiragana": "ひらがなのぶんしょう"
    }
  ]
}
```

### 寿司ネタの追加

1. `images/` ディレクトリに新しいSVGファイルを追加
2. `js/main.js` の `sushiTypes` 配列にファイル名を追加

### デザインの変更

- `css/style.css`: 色、レイアウト、フォントなどのスタイル
- `css/animations.css`: アニメーション効果
